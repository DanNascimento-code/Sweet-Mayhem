# Character voice provenance

All WAV files in this directory were generated locally for this project with
Chatterbox Nano using the built-in model voice. No external speaker reference
or cloned performer was used.

- Model: `ResembleAI/chatterbox-nano`
- Project: <https://github.com/resemble-ai/chatterbox>
- License: MIT
- Source commit: `5de7a54aa4e5e2baadb0182dde554908b48b85c2`
- Sample rate: 24 kHz
- Format: PCM 16-bit WAV
- Watermark: built-in PerTh neural audio watermark

`generation-report.json` records the dialogue identity, acting profile,
generation controls, duration and SHA-256 hash for every output file.

The reproducible generation pipeline is stored in `tools/chatterbox` at the
repository root.
