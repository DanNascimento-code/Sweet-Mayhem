# Voice reference

Place an original or explicitly authorized English voice clip in this folder.

Recommended recording:

- 8 to 12 seconds of clean speech;
- an adult woman performing a youthful character voice;
- sharp, commanding and slightly angry delivery;
- no music, effects, echo or background noise;
- WAV preferred, with a normal speaking volume and no clipping.

Do not use audio from Kuromi, an actor, streamer or another identifiable person
without explicit permission to synthesize that voice.

Reference recordings are ignored by Git and must be provided locally.
